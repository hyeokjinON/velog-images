# velog-images

velog(https://velog.io/@hyeokjinon) 글에 넣는 그림(PNG)을 모아 두는 공개 저장소입니다.

- `java-coding-test/NN/` — [Java 코테 리부트] 시리즈 N편의 그림 (직접 그린 풀이 그림. 문제 지문 캡처는 넣지 않는다)
- `bank-transfer/NN/` — [은행 연동 송금 서비스] 시리즈 N편의 그림 (사이드 프로젝트 https://github.com/hyeokjinON/bank-transfer)

그림의 원본 SVG 도 같은 폴더에 둔다. 글에서는 `https://raw.githubusercontent.com/hyeokjinON/velog-images/main/<경로>.png` 로 연결한다.
